    Methodology

    Pipeline, statistical protocol and modelling choices

    Data pipeline

    everything below ran locally, in order

      Statistical protocol

      • Pearson / Spearman — linear and rank correlation between export and import values; national series (n=8) and HS-chapter cross-section (n=98, FY2024-25). p-values reported; with n=8 the national test is indicative only.
      • One-way ANOVA — response: ln(total bilateral trade ₹ Cr) of each partner country; factor: region (FY2024-25). F statistic, df, p-value and effect size η². Log transform pre-registered to reduce heavy right skew.
      • Chi-square — contingency: region × trade profile (export-surplus vs import-surplus partner), regions with ≥15 partners retained. χ², df, p, Cramér's V; expected counts verified ≥5.
      • Kruskal-Wallis — non-parametric robustness check of the ANOVA on the same groups; H statistic, p-value, ε² = H/(n−1).

      Modelling protocol

      • Features (all lag-1, known at forecast time): export_lag1, import_lag1, balance_lag1, export_share_lag1. No same-year information ever enters a prediction.
      • Models: Persistence (ŷₜ = yₜ₋₁), Linear Regression (OLS), Random Forest (500 trees, depth 3, seed 42).
      • Time-aware evaluation: expanding-window one-step-ahead backtest for FY2021-22…FY2024-25 — each target year predicted by models trained strictly on earlier years. Time series are never shuffled or split randomly.
      • Out-of-sample validation: models refit on FY2018-19…FY2024-25 predict FY2025-26; the published FY2025-26 actuals (year now complete) serve as the hold-out check. FY2026-27 values on the Forecast page are projections with no published actual — clearly labelled.
      • Metrics: MAE and RMSE in ₹ Cr; R² is unit-free. Pooled over backtest points; every model is compared against the Persistence baseline.

      Animation philosophy

      • Every animation encodes information: rank changes in the Top-10 bars show re-ordering directly; the forecast line changes from solid to dashed exactly where history ends; KPI numbers count up to signal scale; the sidebar indicator slides to show position in the site.
      • Loading sequence completes in under 1.5 s; reveals are scroll-triggered once; all motion respects prefers-reduced-motion.

        Disclaimers

        • All figures are reproduced exactly as published by TradeStat EIDB on the retrieval date; nothing is imputed, scaled or synthesised.
        • Predictions shown anywhere on this dashboard are statistical exercises based on historical patterns — not official forecasts of the Government of India.
        • Descriptive statistics, test statistics and model outputs are computed from the downloaded tables only; no external dataset is used anywhere on this site.
        • Region mapping is an analyst-added classification (UN M49-inspired) used solely for aggregation; it is not part of the TradeStat output.
